.NET source generator · MIT

LLM prompts the compiler can check.

Write each prompt as a .prompt.toml file. At build time TypedPrompt turns it into a C# class with one constructor parameter per variable. Forget a value or mistype a placeholder, and the build fails - not production.

dotnet add package TypedPrompt --prerelease

A file in, a class out

The file name becomes the class name. Variables become typed parameters; defaults become optional ones.

Why TypedPrompt

Prompts are code your model runs. Treat them like code.

  • Checked at build time

    Thirteen diagnostics at the file and line: undeclared placeholders, unused variables, bad TOML, wrong value types, invalid JSON schemas - with “did you mean” hints.

  • Nothing at runtime

    No parsing, no reflection, no TOML library in your app. Generated code just concatenates text. Safe for AOT and trimming.

  • Any LLM SDK

    Render-only by design. You get messages, model settings and an output schema; you choose the client.

  • Versioned by content

    Every prompt carries a hash of what the model actually sees. Log rendered.Version with each answer and know exactly which prompt produced it.

  • Few-shot examples

    Add [[examples]] sections; they are sent as user/assistant pairs between the system and user text.

  • One small package

    Runtime for .NET Standard 2.0, .NET 8 and .NET 10 with zero dependencies. Files in Prompts/ are picked up automatically.

Get started

Works in any project on .NET 8 or later, and in .NET Standard 2.0 libraries, with C# 9 or later.

  1. Install the package

    One package holds both the runtime and the generator.

    dotnet add package TypedPrompt --prerelease

  2. Add a prompt file

    Put it in a Prompts folder. Any *.prompt.toml there is included.

    # Prompts/greeting.prompt.toml
user = "Say hello to {{name}}."

[variables.name]
type     = "text"
required = true

  3. Build and use the class

    It lives in <RootNamespace>.Prompts.

    var rendered = new GreetingPrompt(name: "Ada").Render();

The full file format, every diagnostic and the settings are in the README.
